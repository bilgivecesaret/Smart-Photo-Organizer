# Smart-Photo-Organizer
A Mobile App for Summarizing and Cleaning Up Photo Collection 

This project is a mobile application that aims to organize the irregular 
and unnecessary photo piles accumulated on mobile devices with smart analysis 
and summarize them to the user. It detects similar, blurry, low-quality 
or unnecessary photos in the users' gallery and suggests them to delete 
or group them. It also creates albums that summarize important moments.

# Comprehensive Features:

+ Detection of similar photos with image analysis

+ Finding blurry and low-resolution photos

+ Recognizing important moments (e.g. travel, birthday, ceremony, etc.)

+ Creating albums and summarizing

+ Smart deletion suggestions

+ Automatic tagging (face, date, location, etc.)

+ Providing cleaning report to the user
